# 📕 راهنمای کامل مالک — دستیار Z فروشگاه VPN | STAR

> این فایل مال خودته؛ همه‌چیزی که لازم داری تا بدون هیچ ایجنتی کل سیستم رو
> خودت مدیریت، بکاپ و بازیابی کنی. آخرین نسخه همیشه داخل فایل بکاپ و پنل
> وب موجوده.

---

## ⚡ اگه کل سرور/اکانت از بین رفت — یک دستور نجات

بکاپ ساعتیِ خودکار همه‌چیز (کد، دیتابیس، سشن تلگرام، تنظیمات، فاکتورها) را در
ریپوی خصوصی گیت‌هاب `CiaNetIR/agent` نگه می‌دارد. روی هر سرور لینوکسی جدید
(مثلاً یه محیط ابری Z.ai تازه) فقط این یک خط را به ایجنت بده یا خودت اجرا کن:

```bash
bash <(curl -fsSL -H "Authorization: Bearer <TOKEN>" \
  https://raw.githubusercontent.com/CiaNetIR/agent/main/recovery/bootstrap.sh) \
  --token <TOKEN>
```

`<TOKEN>` = توکن گیت‌هابت (ghp_…). **این خط + توکن را حتماً توی نوت آفلاین خودت
ذخیره کن.** بعد از اجرا، همه‌چیز (حتی رمز پنل و لاگین تلگرام) دقیقاً برمی‌گردد.
جزئیات کامل: فایل `RESTORE.md` در ریپو + `recovery/bootstrap.sh --help`.

## ۱) این سیستم چیه؟

یه دستیار هوش مصنوعی به اسم **Z** که روی سرور ابری ۲۴ ساعته روشنه و:

- به پیام‌های دایرکت مشتری‌های فروشگاه (به وقت تهران) جواب آدمیزادی میده
- هر پیامش آخرش این فوتر رو می‌چسبونه (نشونه‌ی پیام باته):
  «من یک دستیار هوش مصنوعی هستم. پشتیبانی آفلاین است.»
- **Saved Messages تلگرامت = اتاق فرمان توئه**: هرچی بنویسی براش اجرا می‌کنه
- هیچ دستوری — حتی از خودت — خاموشش نمی‌کنه (طبق خواسته خودت)
- مدل مغزش `glm-4-plus` با حالت تفکر فعاله (قوی‌ترین موجود)

## ۲) نقشه اطلاعات — چیا کجان و اگه هارد بسوزه چی می‌مونه؟

| لایه | کجا | اگه سرور ریست بشه؟ |
|---|---|---|
| ۱. کد واتچر | `~/tg-tools/` | ❌ پاک میشه |
| ۲. سشن تلگرام + تنظیمات | `~/my-project/.secrets/` (tg.env، watcher-config.json، panel.env) | ✅ معمولاً می‌مونه (حجم ماندگار پروژه‌ست) |
| ۳. آینه کد + همین راهنما | `~/my-project/tg-tools-backup/` | ✅ مثل لایه ۲ |
| ۴. **بکاپ کامل توی تلگرام** | فایل‌های zip توی **Saved Messages** خودت | ✅✅ **مادام‌العمری می‌مونه — ابر تلگرام** |

**نتیجه:** حتی اگه کل سرور بسوزه، از فایل zip داخل Saved Messages همه‌چیز
برمی‌گرده — بدون نیاز به کد ورود جدید تلگرام، چون سشن هم داخل zip هست.

### فایل‌های کلیدی

```
~/tg-tools/watcher/watcher.py        ← مغز اصلی (شخصیت + منطق) — قابل ویرایش
~/tg-tools/watcher/watcher_ctl.sh    ← دکمه‌های روشن/خاموش/وضعیت
~/tg-tools/watcher/supervisor.sh     ← نگهبان که واتچر رو زنده نگه می‌داره
~/my-project/.secrets/tg.env         ← سشن تلگرام + API (⛔ محرمانه)
~/my-project/.secrets/watcher-config.json  ← بلاک‌لیست + قوانین دائمی
~/my-project/.secrets/panel.env      ← رمز پنل + کلید ترمینال
~/my-project/tg-tools-backup/        ← آینه کد + همین راهنما + restore.sh
~/my-project/mini-services/terminal/ ← سرویس ترمینال تحت وب (پورت 3001)
```

## ۳) دسترسی شل به سرور (مهم‌ترین بخش!)

سه راه داری — هیچ‌کدوم به ایجنت وابسته نیستن:

### راه اول: پنل وب (ساده‌ترین)

1. توی همون صفحه‌ای که این پروژه رو می‌بینی، پنل سمت راست (Preview) رو باز کن
   — دکمه «Open in New Tab» هم اگه بود بهتره
2. صفحه «پنل مدیریت Z» باز میشه → **رمز پنل** رو بزن
   (رمز توی پیامی که همراه بکاپ برات فرستادم، توی Saved Messages)
3. تب **«ترمینال»** → دکمه «وصل شو» → یه شل کامل لینوکس!

هر دستوری که بخوای می‌تونی بزنی؛ مثلا `~/tg-tools/watcher/watcher_ctl.sh status`

### راه دوم: از طریق ایجنت (وقتی چت بازه)

کافیه به ایجنتی که پروژه رو باز می‌کنه به فارسی بگی. چند قالب آماده:

- «وضعیت واتچر رو چک کن و آخرین رویدادهاش رو بگو»
- «رمز پنل رو ریست کن و جدید برام بفرست توی تلگرام»
- «شخصیت دستیار رو تغییر بده: از این به بعد ...»
- «از tg-tools-backup/restore.sh یه بازیابی تمرینی رو شبیه‌سازی کن»

### راه سوم: مستقیم با فایل بکاپ (وقتی هیچی جز تلگرام نمونده)

هر سرور لینوکسی با پایتون ۳.۱۰+ — طبق بخش ۷ همین راهنما.

### چیت‌شیت دستورات شل (همونایی که ایجنت هم استفاده می‌کنه)

```bash
~/tg-tools/watcher/watcher_ctl.sh status      # وضعیت کامل + state
~/tg-tools/watcher/watcher_ctl.sh log 50      # ۵۰ رویداد آخر
~/tg-tools/watcher/watcher_ctl.sh pause       # توقف موقت (سشن آزاد میشه)
~/tg-tools/watcher/watcher_ctl.sh resume 15   # ادامه + جبران ۱۵ دقیقه اخیر
~/tg-tools/watcher/watcher_ctl.sh stop        # خاموش کامل (خیلی کم لازمه)
~/tg-tools/watcher/watcher_ctl.sh start 15    # روشن کردن با سوپروایزر
~/tg-tools/watcher/watcher_ctl.sh expiry      # زمان باقی‌مونده پنجره
touch ~/tg-tools/watcher/BACKUP_NOW           # بکاپ فوری به Saved Messages
~/my-project/tg-tools-backup/refresh.sh       # تازه‌سازی آینه کد
~/my-project/tg-tools-backup/restore.sh       # بازیابی کامل از آینه
tail -f ~/tg-tools/watcher/wlog.jsonl         # دنبال‌کردن زنده رویدادها
```

> ⚠️ **قانون طلایی سشن:** تلگرام فقط یه اتصال همزمان قبول می‌کنه.
> قبل از اینکه خودت (یا ایجنت) با ابزارهای تلگرام مثل `send_dm.py` کاری
> کنی، اول `pause` بزن؛ بعد از کارت `resume` کن. وقتی واتچر فعاله،
> هیچ کلاینت دستی دیگه‌ای با سشن باز نکن — وگرنه سشن باطل میشه.

## ۴) فرمان‌های Saved Messages (اتاق فرمان)

از تلگرامت به خودت (Saved Messages) بنویس؛ Z خودش می‌فهمه و اجرا می‌کنه:

| می‌خوای | بنویس (نمونه) |
|---|---|
| وضعیت | «وضعیت» |
| بکاپ فوری | «بکاپ بگیر بفرست» |
| قانون دائمی جدید | «یادت باشه از این به بعد قیمت X هست» |
| پاک کردن همه قوانین | «همه قوانین رو فراموش کن» |
| بلاک مشتری | «به @username دیگه جواب نده» |
| برداشتن بلاک | «به @username دوباره جواب بده» |
| ارسال پیام | «به @username بگو سرویسش فعال شد» |
| برودکست | «به همه مشتری‌ها بگو تخفیف داریم» → بعد «بله» |

نکته‌ها:

- بعد از «بله» برودکست با فاصله ۶–۱۰ ثانیه بین هر پیام ارسال میشه (ضد بن)
- هر تغییری توی بلاک‌لیست/قوانین، یه بکاپ خودکار به Saved Messages می‌فرسته
  (حداکثر یکی در ساعت)
- دستورهای خاموشی/ری‌استارت رد میشن: «Z هیچ‌وقت با هیچ دستوری خاموش نمی‌شه»
- پیام‌هایی که آخرشون فوتر بات نباشه = پیام خودت → اون چت ۱۵ دقیقه ساکت
  می‌مونه تا وسط نری

## ۵) تنظیمات هوش مصنوعی کجاست و چطور عوضش کنم؟

- **شخصیت و لحن و قیمت‌ها:** ثابت توی `watcher.py`، متغیر `SYSTEM_PROMPT`
  — از پنل وب تب «تنظیمات Z» متن کاملش رو می‌بینی
- **قوانین دائمی:** توی `watcher-config.json` بخش `instructions` — با فرمان
  «یادت باشه…» اضافه میشن، با «فراموش کن» پاک
- **مدل:** `glm-4-plus` + حالت تفکر (قوی‌ترین تنظیم ممکن این محیط)
- **محدودیت‌ها:** هر چت ۱۲ جواب/ساعت، کل ۳۰/ساعت، تاخیر ۱۰ ثانیه‌ای

برای تغییر شخصیت: یا از ایجنت بخواه (سریع‌ترین)، یا خودت توی ترمینال پنل
فایل رو ویرایش کن و `watcher_ctl.sh stop && watcher_ctl.sh start 5` بزن.

بعد از هر تغییر، فرمان «بکاپ» بده تا نسخه تازه تنظیمات بره تو Saved Messages.

## ۶) بکاپ‌ها

هر فایل zip بکاپ داخلش داره: کل کدها + **سشن تلگرام** + تنظیمات + بلاک‌لیست
+ قوانین + همین راهنما + `Z-LLM-SETTINGS.txt` (تنظیمات LLM به صورت خوانا)
+ `RESTORE.md` (راهنمای سریع بازیابی).

سه راه بکاپ گرفتن:

1. **از تلگرام:** توی Saved Messages بنویس «بکاپ»
2. **از پنل وب:** دکمه سبز «بکاپ بگیر و بفرست» توی تب وضعیت
3. **از شل:** `touch ~/tg-tools/watcher/BACKUP_NOW`

(به‌علاوه: بکاپ خودکار بعد از هر تغییر تنظیمات)

## ۷) بازیابی فاجعه — سه سناریو

### سناریو A: سرور ریست شده ولی پروژه (`my-project`) سر جاشه

```bash
~/my-project/tg-tools-backup/restore.sh
```

همین. کد برمی‌گرده، سشن چک میشه، واتچر روشن میشه.

### سناریو B: همه‌چی پاک شده — فقط تلگرام مونده

1. آخرین فایل `z_backup_….zip` رو از **Saved Messages** دانلود کن
2. یه چت جدید با ایجنتی باز کن، فایل رو بهش بده و بگو:
   «این بکاپ دستیار Z است؛ طبق RESTORE.md داخلش همه‌چیز رو برگردون»
3. یا خودت روی هر لینوکسی با پایتون ۳.۱۰+:

```bash
unzip z_backup_<date>.zip -d z-restore && cd z-restore
pip install telethon
mkdir -p ~/my-project/.secrets ~/tg-tools/watcher
cp secrets/tg.env secrets/watcher-config.json ~/my-project/.secrets/
cp tg_common.py login_phone.py poll_chat.py send_dm.py inspect_dms.py overview_dms.py ~/tg-tools/
cp watcher/* ~/tg-tools/watcher/ && chmod +x ~/tg-tools/watcher/*.sh
python3 -c "import telethon, asyncio; from telethon import TelegramClient; \
  print('telethon ok')"
~/tg-tools/watcher/watcher_ctl.sh start 15
```

### سناریو C: حتی سشن هم از دست رفته (بدترین حالت)

سشن فقط با **شماره خودت + کد پیامکی + رمز دو مرحله‌ای که فقط توی ذهنته**
دوباره ساخته میشه:

```bash
cd ~/tg-tools && python3 login_phone.py   # تعاملی؛ شماره، کد، رمز ۲FA
~/tg-tools/watcher/watcher_ctl.sh start 15
```

مهم: ایجنت هم می‌تونه این لاگین رو برات انجام بده — فقط کد تلگرام رو که
میاد باید بهش بدی (رمز ۲FA رو اگه خواستی بده، ولی بعدش عوضش کن).

## ۸) قوانین امنیتی (مهم)

1. **فایل zip بکاپ = کلید کامل اکانتته.** هیچ‌وقت به کسی ندیش، هیچ‌جا
   آپلودش نکن. فقط توی Saved Messages خودت بمونه.
2. **یه کلاینت بیشتر روی سشن نباشه** — قبل هر کار دستی: `pause`
3. **رمز ۲FA و بازنشانی اکانت:** دستیار به هیچ شکلی واردش نمیشه (طراحی
   عمدی). هیچ‌وقت لینک‌های tfago / abok رو نزن و به کسی هم ندی.
4. **رمز پنل وب** عوض کردنیه: توی شل بزن
   `bash ~/my-project/tg-tools-backup/reset-panel-password.sh`
   (یا از ایجنت بخواه). رمز جدید همون‌جا نمایش داده میشه — یادداشتش کن.
5. خاموش کردن کامل ترمینال: توی `~/my-project/.secrets/panel.env` مقدار
   `PANEL_TERM=0` بذار و صبر کن یا سرویس رو ری‌استارت کن.
6. همه دستورات ترمینال توی `mini-services/terminal/term-audit.log`
   ثبت میشن (برای پیگیری امنیتی خودت).

## ۹) پنل وب — راهنمای سریع تب‌ها

| تب | چی توشه |
|---|---|
| **وضعیت** | فعال/غیرفعال بودن واتچر، آمار امروز به وقت تهران، رویدادهای اخیر، دکمه بکاپ فوری |
| **تنظیمات Z** | متن کامل شخصیت، مغز فرمان، قوانین دائمی، بلاک‌لیست، مدل و محدودیت‌ها |
| **راهنما** | همین فایل به صورت مرتب + دکمه دانلود |
| **ترمینال** | شل کامل لینوکس (فقط یه جلسه همزمان، ۳۰ دقیقه بی‌کاری = قطع خودکار) |

پنل با نشست مرورگرت قفل میشه (بعد از بستن مرورگر دوباره رمز می‌خواد) و ۵
رمز اشتباه = ۵ دقیقه قفل.
